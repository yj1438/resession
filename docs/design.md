# ReSession 设计文档

## 1. 背景与问题

Claude Code 的会话在关闭后难以找回：`/resume` 只显示当前项目、当前机器的会话。
现有的 CLI 工具（chronologos/cc-sessions）解决了"找到"，但终端形态的浏览与回放体验有限；
现有的 GUI 项目（opcode / Crystal / Vibe Kanban）要么在会话外面包了一层代理，
要么是重型编排平台（2026-09 调研结论，见对话记录）。

## 2. 目标

- **G1 会话找回**：跨全部项目（后续含跨机器）浏览、搜索、恢复 Claude Code 会话
- **G2 原生恢复**：恢复 = 在内嵌真终端中运行 `claude --resume <id>`，Claude Code 的 TUI 原样运行，ReSession 不介入会话内容
- **G3 轻量**：安装包小、内存占用低、启动快；不常驻、不改 Claude Code 配置
- **G4 可回放**：恢复前能预览会话转录（富文本渲染，优于终端预览）
- **G5 可扩展**：架构上预留多 agent（Codex 等）接入点，但不提前实现

## 3. 非目标

- ❌ 不做 Claude Code 的替代品或协议代理（不走 SDK/headless 模式重构 UI）
- ❌ 不做任务编排 / kanban / 多 agent 并行调度
- ❌ 不实现 agent 特有功能的统一化（如 checkpoint），核心只依赖"列表/回放/恢复"公共集
- ❌ 不自建会话存储；会话数据的唯一事实来源永远是各 agent 的本地文件

## 4. 设计原则

| 原则 | 含义 |
|---|---|
| 原生会话唯一事实源 | 只读 `~/.claude/projects/`，只写"用户显式操作"（M3+ 的备注等）到自己的配置 |
| 薄壳 | UI 组件全部用现成轮子：列表/虚拟滚动用 React，终端用 xterm.js，PTY 用 portable-pty |
| Provider 纪律 | 任何组件不得直接接触 `~/.claude` 或写死 claude 命令，必须经过 `SessionProvider` |
| 归一化 IR | 转录渲染只吃统一的中间表示（IR），各 agent 原始格式只在适配器内解析 |
| 宽容解析 | JSONL 是私有格式会演化：未知字段跳过、未知行类型忽略、解析失败降级显示原始 JSON |

## 5. UI 布局

```
┌────────────────────────────────────────────────────────────┐
│  🔍 全局搜索（项目名 / 摘要 / 全文，Ctrl+K 聚焦）              │
├──────────────┬─────────────────────────────────────────────┤
│  会话列表     │  [转录] [终端]  ← 标签页                     │
│              │                                             │
│  项目分组     │   转录：IR 渲染的只读回放                     │
│  · 相对时间   │   （markdown、代码高亮、工具调用折叠）          │
│  · 摘要/标题  │                                             │
│  · 消息数     │   终端：xterm.js + portable-pty              │
│              │   运行 claude --resume <id>，完全交给原生 CLI  │
├──────────────┴─────────────────────────────────────────────┤
│  状态栏：会话总数 / provider / PTY 状态                       │
└────────────────────────────────────────────────────────────┘
```

交互核心路径：**搜索 → 选中 → 转录确认（找回记忆）→ 切终端（原生恢复）**。

## 6. MVP 范围（M1）

只做四件事：**列表 → 回放 → 恢复 → 搜索**。

- 列表：扫描本地全部项目，按修改时间倒序，显示摘要/时间/消息数
- 回放：IR 只读渲染（M1 允许纯文本形态，M2 升级富文本）
- 恢复：选中会话 → 终端标签页自动起 PTY 运行 resume 命令
- 搜索：标题/摘要/项目名模糊匹配（M2 做全文）

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| JSONL 私有格式随版本变化 | 宽容解析 + data-formats.md 跟踪观测；解析层单测用真实样本固定 |
| Windows ConPTY resize 闪烁 | 接受（VS Code 同款问题）；必要时延迟重绘 |
| 找不到 claude 二进制 | binary.rs 多路径探测 + 设置页手动指定（M2） |
| 大会话文件（几十 MB JSONL） | 流式解析；转录虚拟滚动；索引摘要与正文分离存储（M2） |
